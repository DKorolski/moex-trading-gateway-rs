2. Параметры модели — уже совпадают, перенастройка не требуется

  Инструмент FINAM: IMOEXF@RTSX; tick=0.5; шаг количества=1.
  Только IntradayBreakout; live_mr_entries_enabled=false.
  Закрытые M10, 600 секунд; candle-start label, не время получения.
  Model session: 07:00:00..23:49:59 MSK; выходные исключены.
  bo_k=0.53; bo_stop1_range=0.51; bo_stop2_range=0.35.
  bo_big_move_threshold=0.025.
  bo_min_range=1.01, mode=absolute: пункты, не проценты.
  bo_wait_hours=3.0 от actual today_start, не от запуска процесса.
  orchestrator_breakout_eod_mode=same_day.

Структурная сверка TOML с фиксированным FINAM profile: 14/14 выбранных параметров
совпали (8 bo_*, MR flag, две границы model session, EOD mode, weekends, tick).
Дополнительно подтверждены tf_sec=600 и три настройки запроса истории по 4.
Фактическую полноту четырех завершенных модельных сессий проверять по данным:
четыре календарных дня могут не содержать четыре допустимые сессии.
Праздники проверять календарём; номинальные sparse M10 не заполнять фиктивными M1.

По просмотренному FINAM source:
  входы строго выше/ниже C +/- 0.53*R; равенство не является сигналом;
  Stop2 проверяется раньше Stop1; Stop1 только на label minute=50;
  EOD label 23:30; запрещены новые same-day entries на/после этой метки.
  was_long_today/was_short_today, owner и pending сохраняют свой lifecycle.
23:30 M10 закрывается в 23:40; время label/available/received/processed различается.
Пропущенный EOD, поздний бар или недоступный execution не означают успешный flat.
Это статическая сверка, не новый replay, не доказательство текущего ALOR binary.

3. Явные отличия, которые сохраняем

ALOR reference qty=6. FINAM shadow оставляем qty=1 (существующий профиль).
Сравниваем сигналы, нормализованную сторону/позицию и points per contract;
денежный PnL и raw qty не объявляем одинаковыми. FINAM live qty ещё не разрешён:
его владелец согласует отдельно перед GO; qty6 автоматически не переносится.

Новый контракт уточняет прежнее общее утверждение «в ALOR нет riskgate»:
live MR отключён, но фоновый High180/lb120 учёт ALOR остаётся включён.
В FINAM BO-only сохраняем Disabled gate/ledger/seed — это намеренное сужение
до BO parity, не полная копия ALOR operational state. MR PnL не является BO stop.
Не возвращаем 120-сессионный прогрев и не изменяем ALOR ledger/контуры.

4. Следующий узкий source scope для reviewer

Сохранить приведённые параметры и существующий Hybrid callback. Добавить
отдельный candle-only shadow feedback: после принятого закрытого M10 и расчёта
intent — условный full fill по close этого бара, затем обновление виртуальной
позиции до следующего model step. Цена close — допущение симуляции, не обещание
реальной цены Market. Время исполнения не датировать задним числом.
Не выдавать это за наблюдаемую post-intent QUOTES: отдельные policy identity,
provenance и новый shadow segment/state. Прежнее quote-based evidence сохранить.
В replay обе стороны используют одинаковые начальное состояние и fill policy.

QUOTES не должны блокировать новый candle-only shadow. Это не разрешение
ослаблять freshness текущего quote-based профиля. Проверки реальных BARS,
finality, dedup, gaps, auth rotation/reconnect и bounded stop сохраняются.
Текущий установленный runner и его обязательные каналы здесь не менялись.
Не добавлять MR, LIMIT/bracket simulator, новый Redis/recovery framework.

Минимальная проверка: общие M10 -> anchors/state -> BO intents; long/short,
строгие границы входа, обе stop-причины и приоритет, EOD/no re-entry, weekend,
дубликаты, warmup без исторических live intents и явный restart segment.
Онлайн-наблюдение подтверждает доставку баров/EOD отдельно от исторического replay.
Отличия feed, alpha logic, virtual feedback и broker execution учитывать отдельно.

5. Переход к live micro

Параметры BO остаются теми же; виртуальный fill заменяется фактическими
ACK/order/fill/position events через FINAM adapter, а не ALOR CWS протоколом.
Accepted != Filled; частичные/поздние fills и uncertain send не разрешают
слепой повтор полного Market. Нужны request identity, dedup, reconciliation,
ограничение exit подтвержденным остатком, restart с pending и EOD runbook.
Проверку цены/ликвидности для реальных заявок согласовать отдельно: независимость
shadow от QUOTES не означает готовность отправлять live без необходимых checks.

Последовательность: review узкой смены feedback -> source/tests -> отдельно
разрешённые установка и shadow-наблюдение -> parity review -> отдельный micro GO.
Shadow остаётся readonly; FINAM order submission/POST/DELETE, broker dispatch,
реальные заявки и изменения действующих VPS/DB/ALOR state не разрешены этим файлом.
В рамках данной сверки изменена только документация; Rust/конфиги запуска,
установленные бинарники, таймеры, позиции и токены не изменялись.
